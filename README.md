### [subgraph-dips-indexer-selection (IISA)](https://github.com/edgeandnode/subgraph-dips-indexer-selection) (Python)

This service uses a selection algorithm to pick the best indexers to serve paid indexing agreements on each subgraph, minimising gateway cost and latency while maximising decentralisation, success rate and uptime.

### [rewards-eligibility-oracle](https://github.com/graphprotocol/rewards-eligibility-oracle) (Python)

This oracle decides which indexers qualify for The Graph's indexing rewards, using a binary eligibility algorithm and records the decision into the [RewardsEligibilityOracle contract](https://arbiscan.io/address/0x02753bae61c08abd4351bce7f48524935c2cc78e) on Arbitrum.
